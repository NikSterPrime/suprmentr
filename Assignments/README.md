## Overview

SuprMentr is a collection of projects, assignments, and learning artifacts related to the SuprMentr initiative. This repository groups source code, notebooks, tests, and supporting scripts used for development and evaluation.

## Repository layout

- src/ — main source code (library / app)
- notebooks/ — exploration and analysis notebooks
- assignments/ — assignment descriptions and starter code
- tests/ — unit and integration tests
- docs/ — documentation and design notes
- scripts/ — helper and automation scripts

(If a directory listed above does not exist, create it as needed.)

## Requirements

- Python 3.8+
- Recommended: virtual environment
